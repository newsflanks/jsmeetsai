Vue Sandbox

Vue is a sort of poor man's React. Many times you don't really need the complexity of React to deploy a straight-forward and easy-to-use JS app driven by an AI backend. But if the front-end is going to evolve into a much more complex interface, then you should use React. In any case, the best way to quickly create your prototype is to use Node templating systems and then move to React or Vue once you get everything basically right.
